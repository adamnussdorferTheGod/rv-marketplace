**Part B: Create FlatSegment type and flattenSegments utility**

Define inline in CompositionCanvas.tsx (or as a named export if needed by other files):

```typescript
interface FlatSegment {
  segment: VideoSegment;
  actIndex: number;
  actType: ActType;
  globalIndex: number;
}

function flattenSegments(acts: VideoAct[]): FlatSegment[] {
  const flat: FlatSegment[] = [];
  acts.forEach((act, actIndex) => {
    act.segments.forEach((segment) => {
      flat.push({ segment, actIndex, actType: act.type, globalIndex: flat.length });
    });
  });
  return flat;
}
```

This flattens the nested `acts[].segments[]` into a linear array with act metadata, enabling simple `currentIndex++` advancement while preserving act boundaries for Phase 13 chapter navigation.

**Part C: Create CompositionCanvas.tsx**

Component consumes `useVideoWalkthrough()` for state + action callbacks and uses `useTimeline` for rAF-driven playback.

Props: None — all data comes from context.

Implementation:

1. **Get context:** `const { state, data, tick, advanceSegment, end } = useVideoWalkthrough();`

2. **Flatten segments:** `const flatSegments = useMemo(() => data ? flattenSegments(data.acts) : [], [data]);`

3. **getActIndex helper:** `const getActIndex = useCallback((segIndex: number) => flatSegments[segIndex]?.actIndex ?? 0, [flatSegments]);`

4. **Wire useTimeline:**
```typescript
useTimeline({
  isPlaying: state.status === 'playing',
  segments: flatSegments.map(f => f.segment),
  currentSegmentIndex: state.currentSegmentIndex,
  onTick: tick,
  onSegmentAdvance: advanceSegment,
  onEnd: end,
  getActIndex,
});
```

5. **Image preloading:** Use a `useEffect` that preloads 2 images ahead of the current segment during playback. Fire-and-forget `new Image(); img.src = url;` pattern. This ensures the next photo is in the browser cache before its segment starts:
```typescript
useEffect(() => {
  for (let i = 1; i <= 2; i++) {
    const next = flatSegments[state.currentSegmentIndex + i];
    if (next) {
      const img = new Image();
      img.src = next.segment.photoUrl;
    }
  }
}, [state.currentSegmentIndex, flatSegments]);
```

6. **Two-layer A/B crossfade rendering:**

The critical pattern: use `currentIndex % 2` to determine which of two KenBurnsLayer slots is "active" (Layer A or Layer B). This prevents React from remounting the same DOM element on segment change, which would restart CSS animations.

```typescript
const currentIndex = state.currentSegmentIndex;
const currentSeg = flatSegments[currentIndex];
const previousSeg = currentIndex > 0 ? flatSegments[currentIndex - 1] : null;
const isLayerAActive = currentIndex % 2 === 0;
const isPaused = state.status === 'paused';
```

Render two KenBurnsLayer instances:
- **Layer A**: When `isLayerAActive`, shows `currentSeg` at opacity 1; otherwise shows `previousSeg` fading out at opacity 0.
- **Layer B**: When `!isLayerAActive`, shows `currentSeg` at opacity 1; otherwise shows `previousSeg` fading out at opacity 0.

Each layer uses a `key` based on `active-{index}` or `outgoing-{index}` to control React reconciliation. The key is critical: it ensures React reuses the same DOM element for the active photo's lifetime (no animation restart) and unmounts the outgoing photo after the crossfade completes.

Only render a layer if its segment exists (previousSeg can be null on first segment).

```tsx
return (
  <div className={styles.canvas}>
    {/* Layer A */}
    {(isLayerAActive ? currentSeg : previousSeg) && (
      <KenBurnsLayer
        key={isLayerAActive ? `a-${currentIndex}` : `a-${currentIndex - 1}`}
        segment={(isLayerAActive ? currentSeg : previousSeg)!.segment}
        isActive={isLayerAActive}
        opacity={isLayerAActive ? 1 : 0}
        isPaused={isPaused}
      />
    )}
    {/* Layer B */}
    {(!isLayerAActive ? currentSeg : previousSeg) && (
      <KenBurnsLayer
        key={!isLayerAActive ? `b-${currentIndex}` : `b-${currentIndex - 1}`}
        segment={(!isLayerAActive ? currentSeg : previousSeg)!.segment}
        isActive={!isLayerAActive}
        opacity={!isLayerAActive ? 1 : 0}
        isPaused={isPaused}
      />
    )}
  </div>
);
```

This guarantees:
- Only 2 images ever in DOM (COMP-03 constraint)
- 500ms crossfade via CSS opacity transition on KenBurnsLayer's outer div
- No dark flash (both layers overlapping during transition)
- Photo sequencing in array order (COMP-06), driven by data not runtime sort logic
